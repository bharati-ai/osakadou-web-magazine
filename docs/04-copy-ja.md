## areas（大阪エリアガイド）

### areas[1]
- kanji: 北
- name: キタ（梅田・大阪）
- romaji: Kita (Umeda / Osaka)
- desc: JR大阪駅と梅田の各駅が集まる北の玄関口。高層ビルと地下街、昔ながらの飲み屋街が隣り合います。
- day: 買い物も乗り換えも一度に済ませたい日
- stations: 大阪、梅田、東梅田、西梅田、大阪梅田、北新地

### areas[2]
- kanji: 南
- name: ミナミ（なんば・心斎橋）
- romaji: Minami (Namba / Shinsaibashi)
- desc: 道頓堀の川沿いに看板が並び、心斎橋筋の商店街がなんばへと続く繁華街。劇場や食の店も多い街です。
- day: にぎやかな街を食べ歩きしたい日
- stations: なんば、心斎橋、日本橋、大阪難波、JR難波

### areas[3]
- kanji: 中
- name: 中之島・北浜
- romaji: Nakanoshima / Kitahama
- desc: 堂島川と土佐堀川に挟まれた中洲に、美術館や図書館、近代建築が並びます。対岸の北浜は古いビルの残る金融街。
- day: 川沿いで建築と美術を眺める日
- stations: 淀屋橋、北浜、なにわ橋、大江橋、渡辺橋、中之島

### areas[4]
- kanji: 天
- name: 天王寺・阿倍野
- romaji: Tennoji / Abeno
- desc: 天王寺公園や動物園、四天王寺のある街に、あべのハルカスが建つ南の拠点。新旧の景色が隣り合います。
- day: 公園と下町を気ままに歩く日
- stations: 天王寺、大阪阿部野橋、阿倍野、天王寺駅前、四天王寺前夕陽ケ丘

### areas[5]
- kanji: 城
- name: 京橋・大阪城
- romaji: Kyobashi / Osaka Castle
- desc: 大阪城公園の緑と石垣を望むエリア。京橋は複数の路線が交わる乗換駅で、駅前には飲食店が集まります。
- day: お城のまわりを散歩したい日
- stations: 京橋、大阪城公園、森ノ宮、大阪ビジネスパーク、天満橋、谷町四丁目

### areas[6]
- kanji: 港
- name: ベイエリア
- romaji: Bay Area
- desc: 大阪港に面した海辺のエリア。天保山の海遊館やテーマパークがあり、港の景色と海風を感じられる街です。
- day: 海を見ながら、のんびり過ごす日
- stations: 大阪港、コスモスクエア、トレードセンター前、ユニバーサルシティ、桜島、弁天町
